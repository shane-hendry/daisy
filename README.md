# Daisy & Daisy Sans

![Daisy in NetNewsWire](screenshots/Daisy%20Hero.png)

Two [NetNewsWire](https://netnewswire.com/) themes that clean up the content of your RSS feed. One design, two appearances:

- **Daisy** is set in New York
- **Daisy Sans** is set in SF Pro

Learn more about [Daisy and Daisy Sans](https://shanehendry.com/daisy).

<!-- nnw-theme-identity:end -->

## An editor in chief for your feed

Daisy and Daisy Sans bring content design to your RSS feed. They clean up RSS data for a cohesive reading experience.  
  
* Simple, consistent bylines
* Smart title blocks with conditional eyebrows and secondary links
* Timestamps are relative and reveal the exact time on tap
* Clear, interactive footnotes  
* Deduplicates links and content  
* Hides platform-injected content blocks, so you only see what the author intended  
* Support for 30+ languages, right-to-left languages, and XXXXXL font sizes  
  
Daisy's favorite writers get special treatment:  
  
* Titles are deduplicated on untitled posts like [Kottke's](https://kottke.org/) quick links  
* Sponsor, podcast, and issue numbers move to the eyebrow for [Daring Fireball](https://daringfireball.net/), [Six Colors](https://sixcolors.com/), [Snake](https://snake.substack.com/), and more
* [Daring Fireball's](https://daringfireball.net/) linking conventions get special treatment (forgive me, John)  
  
This is all detailed in [content design](docs/content-design.md) and [content rules](docs/content-rules.md). It requires JavaScript and trust me, it's worth it.


## Install

Daisy and Daisy Sans are in beta. [Version 0.2.0](https://github.com/shane-hendry/daisy/releases/tag/v0.2.0) is the latest release.

1. Download the theme (or both), then open the zip:
   - [Daisy](https://github.com/shane-hendry/daisy/releases/download/v0.2.0/Daisy.nnwtheme.zip)
   - [Daisy Sans](https://github.com/shane-hendry/daisy/releases/download/v0.2.0/Daisy.Sans.nnwtheme.zip)
2. On your Mac, drag the **.nnwtheme** file onto the NetNewsWire dock icon. On iPhone and iPad, save them to Files, then open NetNewsWire, go to **Settings → Theme → +**.
3. Select **Daisy** or **Daisy Sans** in the list of themes in NetNewsWire

See [all releases](https://github.com/shane-hendry/daisy/releases) for notes and older versions.
