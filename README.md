# Daisy and Daisy Sans

![Daisy in NetNewsWire](screenshots/Daisy%20Hero.png)

Two [NetNewsWire](https://netnewswire.com/) themes by [Shane Hendry](https://shanehendry.com), one design in two typefaces:

- **Daisy** is set in New York
- **Daisy Sans** is set in SF Pro
<!-- nnw-theme-identity:end -->

## The words do all the work

The themes are typeset and designed with extra attention to the little things:

- Simple, consistent bylines: "Matilda Jeffries for Time"
- Relative times: "2 hours ago", "Yesterday"
- Nice, interactive footnote design
- Link deduplication
- Support for 30+ languages and XXXXXL font sizes

Daisy's favorite writers get special treatment:

- Hides titles on untitled posts, like [Kottke's](https://kottke.org) quick links, [Manton Reece's](https://manton.org) posts, and social posts from Mastodon and Bluesky
- Simplifies sponsor, podcast, and issue-numbers in titles from [Daring Fireball](https://daringfireball.net/), [Six Colors](https://sixcolors.com/), [Snake](https://snake.substack.com/), and more
- Treats [Daring Fireball's](https://daringfireball.net) linking conventions uniquely, forgive me John
- Cleans up funky Squarespace and Wordpress stuff

All this requires javascript, and it's worth it.

## Install

Daisy and Daisy Sans are in beta. [Version 0.1.0](https://github.com/shane-hendry/daisy/releases/tag/v0.1.0) is the first release.

1. Download the theme (or both), then open the zip:
   - [Daisy](https://github.com/shane-hendry/daisy/releases/download/v0.1.0/Daisy.nnwtheme.zip)
   - [Daisy Sans](https://github.com/shane-hendry/daisy/releases/download/v0.1.0/Daisy.Sans.nnwtheme.zip)
2. On your Mac, drag the **.nnwtheme** file onto the NetNewsWire dock icon. On iPhone and iPad, save them to Files, then open NetNewsWire, go to **Settings → Theme → +**.
3. Select **Daisy** or **Daisy Sans** in the list of themes in NetNewsWire

See [all releases](https://github.com/shane-hendry/daisy/releases) for notes and older versions.
